# [Medium] Unauthenticated access on GET /openapi.json
**Severity:** Medium (5.1) — base 5.3 (unauth_access); low-criticality asset (-1.0); no valid credentials needed (+0.5); zombie endpoint, likely unmonitored (+0.3)
**Owner:** security-triage (#appsec)  **Status:** OPEN  **OWASP:** API2:2023 Broken Authentication  **CWE:** CWE-306


## Business impact
Endpoint is reachable without authentication.

## Proof (oracle: `differential`)
GET /openapi.json returns the same data without any token

```bash
curl -s -X GET 'http://127.0.0.1:8100/openapi.json'
```
Evidence audit IDs: 1005, 1006 — replay with `python -m tripwire replay <audit_id>`


## Suggested fix
Require authentication at the gateway for this route, or remove it if it is not needed.
