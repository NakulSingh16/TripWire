# [Critical] JWT alg=none accepted on GET /partner/v1/bookings
**Severity:** Critical (10.0) — base 9.1 (jwt_alg_none); asset criticality 1.3 (+0.5); no valid credentials needed (+0.5)
**Owner:** partner-integrations (#partners)  **Status:** OPEN  **OWASP:** API2:2023 Broken Authentication  **CWE:** CWE-347


## Business impact
Account or session integrity is broken: an attacker can act as other users or keep access after logout.

## Proof (oracle: `jwt_accepted`)
alg=none token impersonating a1_agent accepted (bad-signature control rejected with 401)

```bash
# forged header {"alg":"none"}, payload sub=a1_agent
curl -s -X GET 'http://127.0.0.1:8101/partner/v1/bookings' -H 'Authorization: Bearer <FORGED>'
```
Evidence audit IDs: 793, 796 — replay with `python -m tripwire replay <audit_id>`


## Suggested fix
Pin accepted algorithms (algorithms=['HS256'/'RS256']) in the JWT verifier; reject 'none' and unsigned tokens.
